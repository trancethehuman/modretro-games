# Toronto Dispatch

An angled/isometric pixel-art courier game set in a recognisable, compressed Toronto. Take package jobs, plan routes through traffic, brake into corners, and arrive before the deadline. Explore between jobs. Passenger rides and additional vehicles follow the first delivery milestone.

**Status:** editable GB Studio project created, starter ROM built, boot text and basic movement tested. The current setup room is temporary. Isometric city art, driving physics, traffic, and delivery missions are not implemented yet.
