# Toronto Dispatch native project

Created through the ModRetro Chromatic plugin's blank-project tool. Open `project.gbsproj`; scene and asset resources are editable native GB Studio files.

The `Development boot` scene identifies this as a setup build and allows basic workshop movement. City art, isometric rendering, driving and missions remain planned. See [build instructions](../docs/BUILD.md) and [testing record](../TESTING.md).

Starter artwork comes from ModRetro Chromatic plugin 1.0.33. See [provenance](STARTER_PROVENANCE.json), [editable pixel sources](original-art/README.md), and [asset MIT notice](ASSET_LICENSE). The font covers printable ASCII with small-cap lowercase and question-mark fallback. Native metadata retains its [upstream MIT notice](LICENSE).
