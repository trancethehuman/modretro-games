# Editable starter artwork

`recipes.mjs` contains authored tile, sprite and glyph rows. `native-cells.json` contains the final indexed pixels and palettes. These sources were copied unchanged from ModRetro Chromatic plugin 1.0.33.

Eleven font glyphs reuse original Signal Lost title glyphs at commit `5929961b938260ad112b87fc57145b7b23c7a196`; all other starter glyphs, room, player and dialogue UI were authored for the plugin release. Lowercase uses small capitals; unsupported characters fall back to a question mark.

See [provenance](../STARTER_PROVENANCE.json) for source identities and hashes and [asset MIT notice](../ASSET_LICENSE) for the licence. These are development placeholders, not Toronto city art.
