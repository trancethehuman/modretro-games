# Fuller Islands runtime plan

The immediate stage reserves `TD_DISTRICT_ISLANDS=5` while keeping `TD_DISTRICT_COUNT=5`, the world registry, existing stop locations and save version 8 unchanged. It prepares explicit traffic suppression and a shared return-assistance fare query. Actual registration, relocation, source-validator updates and versioned migration follow together in a separately verified milestone. The current ROM must remain playable throughout.

## Ferry and recovery semantics

The current `td_transit.c` already implements the right spoke topology: `10↔20`, `10↔21`, `10↔22`; no direct Island-to-Island ferry. Preserve its fictional 30-second period, two-second boarding window, eight-second trip and ordinary $4 fare. Island-to-Island walking is available through the real authored internal graph. These compressed fares/times are game rules, not current City service or pricing.

Use one BANKED pure query, `td_transit_booking_fare(origin,target,job,cash,district)`, in both pre-boarding UI and deduction. It returns zero **only** for plain origin 20–22, target 10, district 5, no active job, and cash below $4. It otherwise returns the ordinary service fare. This explicitly agreed recovery rule prevents a failed/cancelled courier with insufficient money becoming stranded. Assistance uses the same departure schedule, wait cancellation, paid-state persistence and scene arrival; outward trips and active jobs receive no discount. Show the assistance cue before boarding. No ticket bit, new SRAM field, car teleport or free mission completion is introduced.

Current `td_second` commits an on-foot arrival before queuing its actual destination scene. Failed paid work still completes its trip; blocked landing/failed VM queue retries with `ride_left=1`, without another fare. Preserve this behavior. The mainland parked car's district/position remains fixed throughout every ferry journey. The new scene must include an ordinary way to return after timeout/cancellation and after a zero-cash restore.

The ordinary `td_world_route` contains road seams only and will correctly fail between mainland and Islands. Replace the resulting generic NO ROAD ROUTE objective cue with a bounded ferry cue: heading toward Islands, reach terminal 10; leaving Islands, reach a valid Island dock. Within district 5, show the actual client. Do not insert an invisible mainland foot edge into the seam graph to silence the cue.
