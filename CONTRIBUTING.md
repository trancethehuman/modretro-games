# Contributing

Read `AGENTS.md` and the accepted decisions in `DECISIONS.md` before starting. Use a focused branch and pull request. Explain the player-visible change and include the checks actually performed.

This repository is Toronto Dispatch only. Keep the design, roadmap, decisions and testing record at the root current with each change.

Preserve editable source assets. Include provenance and licence terms for external assets or data. Do not submit commercial ROMs, copied game artwork, credentials, activation codes, or device backups.

Run `make check`. For gameplay changes also build the ROM, run the relevant emulator scenarios, and report hardware testing separately. A repository check pass is not a ROM test.
